# Project instructions

- Use Rust for application code.
- Use Slint as the sole GUI framework.
- Use SQLite through Rust for local persistence.
- Use the Google AI Studio Gemini API for chat and choose a model available on the free tier.
- Use Gemini Live with the Aoede voice for spoken conversation in Filipino, English, and Taglish.
- Keep Gemini API keys in the OS credential store or an environment variable.
- Give each feature its own folder and keep its feature-specific files together there.
- Do not write comments in source code, including documentation comments.
